# 🏋️‍♂️ Daily Fit Boost

A motivational web app that delivers daily fitness quotes and workout songs to keep you inspired!

---

## 🚀 Deployed App

🔗 [Live Demo on Netlify](https://daily-fit-boost.netlify.app)

---

## 🧰 Technologies Used

- React (with functional components and hooks)
- React Router DOM
- CSS Modules
- JavaScript (ES6+)
- Local Storage for saving favorites
- Fetch API for quotes
- Netlify (deployment)
